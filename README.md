# 🔐 Password Strength Analyzer (Java GUI)

A modern **Password Strength Analyzer** built using Java Swing that evaluates the strength of a password in real-time and provides instant feedback.

---

## 🚀 Features

* 🔍 Analyze password strength instantly
* 💪 Categorizes passwords:

  * Weak ❌
  * Moderate ⚠️
  * Strong 💪
  * Very Strong 🔥
* 🎨 Simple and clean GUI (Java Swing)
* ⚡ Fast performance using optimized regex
* 🖥️ Popup-based interface (no terminal needed)

---

## 🖼️ Demo

> Enter your password → Click **Check Strength** → Get instant result!

---

## 🧠 How It Works

The analyzer checks:

* ✔ Password length
* ✔ Uppercase letters
* ✔ Lowercase letters
* ✔ Numbers
* ✔ Special characters

Based on these factors, it assigns a **strength score** and displays the result.
